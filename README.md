# Quant Android Terminal & Universal Floating Overlay

Aplikasi Android Kuantitatif Mandiri dengan Floating Chat Head yang berjalan di atas MetaTrader 5 (MT5).

---

## Cara Kompilasi Otomatis Menjadi APK (Tanpa Komputer / Via HP)

1. **Commit & Push** seluruh file repositori ini ke branch `main` GitHub Anda.
2. Buka tab **Actions** di repositori GitHub browser ponsel Anda.
3. Pilih workflow **Build Quant Android Terminal APK**, lalu klik **Run workflow**.
4. Tunggu build selesai (sekitar 2–3 menit hingga centang hijau).
5. Klik nama run build tersebut, lalu unduh file artifact bernama **`Quant-Terminal-AI-App`**.
6. Ekstrak file zip dan instal file **`app-debug.apk`** langsung di ponsel Android Anda.
